# MAUI Receiver App

Planned component: a .NET MAUI app that receives the ESP32 Bluetooth stream and
displays or records the tremor measurements on supported Apple devices.

The app and ESP32 firmware must use the same Bluetooth transport and message
format. Track those shared decisions in
[`../docs/bluetooth-protocol.md`](../docs/bluetooth-protocol.md).

No MAUI application has been added yet.
